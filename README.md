# Kayak

An AI agent app for your Mac. Agents work in private sandboxes, with models from
Gemini, OpenAI, Anthropic, or running on your Mac.

**Get it:** install [Docker Desktop](https://www.docker.com/products/docker-desktop/),
then download the [Kayak app](https://github.com/omaraflak/kayak-launcher/releases/latest)
and open it.

**From source:** with Docker Desktop running, run `docker compose up --build` and open
<http://localhost:8000>.
