# Web Research & Source Synthesis Skill

Follow these instructions when conducting research:

1. **Deconstruct the Query**:
   - Break the topic into 2-3 specific search queries.
   - Run `web_search` for each query.

2. **Deep-Dive Key Sources**:
   - For high-relevance URLs found in search snippets, use `fetch_url(url)` to read the full body content.

3. **Synthesize & Cite**:
   - Summarize core findings with clear headings.
   - Always include Markdown hyperlinks `[Source Title](URL)` for all facts, benchmarks, and claims.
